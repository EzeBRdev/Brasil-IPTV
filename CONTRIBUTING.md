# Como contribuir com o Brasil IPTV

Obrigado pelo interesse em contribuir!

## 1. Antes de contribuir

Leia as regras em:

docs/REGRAS-DE-AUTORIZACAO.md

## 2. O que você pode contribuir

- Encontrar emissoras brasileiras.
- Enviar comprovações de autorização.
- Corrigir informações de canais.
- Melhorar scripts e documentação.
- Corrigir erros no projeto.

## 3. Como enviar uma contribuição

1. Faça um Fork do repositório.
2. Crie uma branch para sua alteração.
3. Faça as modificações.
4. Verifique os arquivos.
5. Abra um Pull Request.

## 4. Regras importantes

- Não envie canais piratas.
- Não invente links de transmissão.
- Não envie fontes sem autorização comprovada.
- Respeite os direitos das emissoras.
- Explique a origem das informações.

Toda contribuição será revisada antes de ser aceita.

Obrigado por ajudar o Brasil IPTV!
